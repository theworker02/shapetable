# shapetable

Shape digests and table fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/shapetable/

## Install / run

```bash
git clone https://github.com/theworker02/shapetable.git
cd shapetable
node src/cli.js
node --test
```
